# Exercise art — generation worklist

109 drawings, one per exercise. Generated by hand in Gemini web because the API
key has no image quota (all four image models return 429; text generation is
unaffected, which is why the label reader still works).

**Where they go:** `docs/img/exercises/<slug>.png`, using the exact filename in
the list below. The app builds that path from the exercise name, so an image
appears the moment the file exists — no database change, no upload step. Any
exercise without a file keeps the drawn muscle map it has now.

**Format:** PNG, square, 512×512 is plenty. They render at 44px in the list and
about 150px in the exercise sheet.

---

## 1. Paste this once, at the start of a new Gemini conversation

Setting the style once and then asking for exercises one at a time keeps the set
consistent. Starting a fresh conversation per image will not.

> You are going to draw a series of exercise illustrations for a workout app.
> Every image must share one identical house style, because they appear together
> in a list and any drift is obvious.
>
> **Style, fixed for every image in this conversation:**
> - A single stylised human figure — smooth matte grey (#B9C2CE), no face, no
>   hair, no clothing, no skin texture. Think anatomical mannequin, not a person.
> - The muscle being worked is shaded solid red-orange (#E0362A) directly on the
>   figure's body, in the anatomically correct place. It is the only saturated
>   colour in the image.
> - Equipment (barbell, dumbbell, machine, cable, bench) drawn in dark grey
>   (#4A5261) so it reads as present but never competes with the figure.
> - Background: solid very dark charcoal #0E1116, edge to edge. No gradient, no
>   floor, no shadow, no room, no gym.
> - Clean flat shading. No photorealism, no outlines, no gloss, no rim light.
> - Three-quarter view, whole body in frame, captured mid-repetition at the
>   position that makes the movement recognisable.
> - Square image, figure centred with a comfortable margin.
> - Absolutely no text, letters, numbers, labels, arrows, logos or watermarks.
>
> **The test that matters:** each image will be displayed at 44 × 44 pixels.
> Shapes must be bold and well separated. Anything thin, fussy or fine-detailed
> disappears at that size, so simplify aggressively.
>
> Reply "ready" and then I will send exercises one at a time. Draw each one in
> exactly this style. Do not vary it.

## 2. Then send each exercise like this

> Draw: **Bench Press (Barbell)** — highlight the **pectorals** in red-orange.
> Include the barbell and flat bench.

Save the result as the filename from the list. That's it — same one-liner every
time, changing only the name, the muscle and the equipment.

If one comes back wrong, reply "again, but ..." in the same conversation rather
than starting over; it keeps the style anchored.

## Doing it in a sensible order

110 drawings is a lot in one sitting. The list is alphabetical, which is the
worst order to work in — you'll draw eight chest variants scattered across it.

Grouped by muscle, consecutive images look most alike and the style holds best:

- **Chest** — 12, 18, 19, 23, 24, 31, 45–49, 61, 70
- **Back / lats** — 9, 13, 25, 29, 33, 50, 51, 54, 55, 66, 69, 74, 77, 79–81, 89, 93, 101, 102, 104
- **Legs** — 4, 6, 15, 36, 38, 39, 43, 57–59, 62, 63, 75, 76, 87, 98, 103, 110
- **Shoulders** — 3, 35, 53, 56, 64, 71, 72, 84, 86, 88, 90, 91
- **Arms** — 1, 8, 10, 11, 14, 17, 26, 27, 32, 34, 40, 65, 68, 73, 83, 85, 94, 96, 105–109
- **Core** — 2, 16, 30, 41, 60, 67, 78
- **Calves / glutes / other** — 5, 20–22, 28, 37, 42, 44, 52, 82, 95, 97, 99, 100

There's no need to do all of them. The app falls back to the muscle map for
anything missing, so the first twenty cover most of what you actually train.
