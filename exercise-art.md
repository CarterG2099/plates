# Exercise art — generation worklist

103 drawings, one per exercise. Generated by hand in Gemini web because the API
key has no image quota (all four image models return 429; text generation is
unaffected, which is why the label reader still works).

**The commands live in `exercise-prompts.md`** — one ready-to-paste line per
exercise, grouped by muscle, with the equipment named. This file is the why and
the record of what was cleaned up along the way.

**Where they go:** `docs/img/exercises/<slug>.png`, using the exact filename
given in `exercise-prompts.md`. The app builds that path from the exercise name,
so an image
appears the moment the file exists — no database change, no upload step. Any
exercise without a file keeps the drawn muscle map it has now.

**Format:** PNG, square, 512×512 is plenty. They render at 44px in the list and
about 150px in the exercise sheet.

---

## 1. Paste this once, at the start of a new Gemini conversation

Setting the style once and then asking for exercises one at a time keeps the set
consistent. Starting a fresh conversation per image will not.

> You are going to draw a series of exercise illustrations for a workout app.
> Every image must share one identical house style, because they appear together
> in a list and any drift is obvious.
>
> **Style, fixed for every image in this conversation:**
> - A single stylised human figure — smooth matte grey (#B9C2CE), no face, no
>   hair, no clothing, no skin texture. Think anatomical mannequin, not a person.
> - The muscle being worked is shaded solid red-orange (#E0362A) directly on the
>   figure's body, in the anatomically correct place. It is the only saturated
>   colour in the image.
> - Equipment (barbell, dumbbell, machine, cable, bench) drawn in dark grey
>   (#4A5261) so it reads as present but never competes with the figure.
> - Background: solid very dark charcoal #0E1116, edge to edge. No gradient, no
>   floor, no shadow, no room, no gym.
> - Clean flat shading. No photorealism, no outlines, no gloss, no rim light.
> - Three-quarter view, whole body in frame, captured mid-repetition at the
>   position that makes the movement recognisable.
> - Square image, figure centred with a comfortable margin.
> - Absolutely no text, letters, numbers, labels, arrows, logos or watermarks.
>
> **The test that matters:** each image will be displayed at 44 × 44 pixels.
> Shapes must be bold and well separated. Anything thin, fussy or fine-detailed
> disappears at that size, so simplify aggressively.
>
> Reply "ready" and then I will send exercises one at a time. Draw each one in
> exactly this style. Do not vary it.

## 2. Then send each exercise like this

> Draw: **Bench Press (Barbell)** — highlight the **pectorals** in red-orange.
> Include the barbell and flat bench.

Save the result as the filename from the list. That's it — same one-liner every
time, changing only the name, the muscle and the equipment.

If one comes back wrong, reply "again, but ..." in the same conversation rather
than starting over; it keeps the style anchored.

## Already fixed in the app

Both problems below were found while writing this list — generating a prompt per
exercise meant reading all 111, which nothing else had done. Both are corrected
in the database now; this section is the record, not a to-do.

**Two duplicates, merged.** Each pair was the same exercise entered twice:

| Kept | Removed | Why |
|---|---|---|
| `Bench Press (Barbell)` — 264 sets | `Barbell Bench Press` — 0 sets | no history to lose |
| `Leg Raise Parallel Bars (Weighted)` — 117 sets | `Leg Raise Parallel Bars Weighted` — 3 sets | the 3 sets were moved across first, not discarded |

**Six more duplicates, found later and deleted.** Writing a prompt per exercise
surfaced these; checking the history rather than assuming is what made them safe
to remove. Every one had zero sets — including soft-deleted ones — and zero
routine references:

| Kept | Sets | Deleted | Sets |
|---|---|---|---|
| `Incline Bench Press (Dumbbell)` | 237 | `Incline Dumbbell Press` | 0 |
| `Triceps Extension (Dumbbell)` | 233 | `Overhead Triceps Extension` | 0 |
| `Bent Over Row (Barbell)` | 158 | `Barbell Row` | 0 |
| `Squat (Barbell)` | 150 | `Back Squat` | 0 |
| `Straight Arm Lat Pulldown (Cable)` | 117 | `Straight-Arm Pulldown` | 0 |
| `Bicep Curl (Dumbbell)` | 63 | `Dumbbell Curl` | 0 |

That leaves 103 exercises, and every filename collision is gone.

**Names normalised.** The weight form now always trails in parentheses —
`Bench Press (Dumbbell)`, not `Dumbbell Bench Press` — across 19 renamed rows.
Two exercises differing only by equipment now sort together and read as
variants, which is what they are.

Worth knowing: `muscle-map.js` infers the muscle and the movement archetype from
the *name* for the 32 exercises with no recorded `primary_muscle`, so a rename
can silently change which figure lights up. All 19 were checked to classify
identically before and after.

**Seven wrong or missing muscles, corrected:**

| Exercise | Was | Now |
|---|---|---|
| Bench Press (Barbell) | triceps | chest |
| Rear Delt Reverse Fly (Machine) | unset — inferred as chest | rear deltoids |
| Hip Adduction (Machine) | quadriceps | adductors |
| Hip Abduction (Machine) | unset | gluteus medius |
| Deadlift | lats | lower back |
| Swing (Kettlebell) | unset | glutes |
| Decline Sit Up | unset | core |

**Cardio has no single muscle.** Cycling, Spinning and Stair Machine are marked
"no highlight" in the prompts — draw the figure and equipment in grey with no red
at all, rather than inventing a target.
